👥 HR Management Dashboard

ภาพรวมกำลังพลและสวัสดิการ

Dashboard ของคุณพร้อมใช้งาน

✅ Dashboard เชื่อมต่อกับ Google Sheets 7 ไฟล์เรียบร้อยแล้ว

ข้อมูลจะอัพเดตอัตโนมัติเมื่อคุณรีเฟรษหน้า หรือกดปุ่ม Sync

📋 ไฟล์ที่เชื่อมต่อ

  • ✅ 01 Master_Headcount (อัตรากำลัง)
  • ✅ 02 Master_Emp (ข้อมูลพนักงาน)
  • ✅ 03 Master_Flex (Flex Benefit)
  • ✅ 05 Master_OT (ค่าล่วงเวลา)
  • ✅ 07 Health_Claims_Track_Sheet (ประกันสุขภาพ)
  • ✅ Flex Benefit (เพิ่มเติม)
  • ✅ Absenteeism (ข้อมูลขาดงาน)

📝 วิธีการใช้งาน

  1. เข้าไปดู Dashboard ที่ https://chayarn27.github.io
  2. ข้อมูลจะโหลดโดยอัตโนมัติจาก Google Sheets
  3. ถ้าต้องการอัพเดตข้อมูล ให้รีเฟรษหน้า (F5)
  4. เมื่อมีการเปลี่ยนแปลงใน Sheet ข้อมูลจะปรากฏขึ้นอัตโนมัติ
  5. คุณสามารถแชร์ URL ให้คนอื่นใช้งานได้
